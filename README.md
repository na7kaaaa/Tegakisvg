# tegaki.svg（仮）— MVP

手書き文字の画像を1文字ずつ検出し、SVGとして書き出すブラウザ完結型ツール。

## 起動方法

1. `index.html` をブラウザで直接開く（ビルド不要）
2. インターネット接続は必要（ImageTracer.js / JSZip をCDNから読み込むため）
3. 画像処理自体はすべてブラウザ内で完結し、外部送信は一切なし

## 使用方法

1. **STEP1** — PNG/JPG/JPEG画像をドラッグ＆ドロップ、またはクリックして選択
2. **STEP2** — 検出結果プレビューを見ながらスライダーで調整
   - **Threshold**：二値化の強さ（自動Otsu値からのオフセット）
   - **Noise**：小さすぎる検出領域の除去
   - **Merge**：近いパーツ（濁点・離れた筆画など）を1文字にまとめる感度
   - **Smooth**：SVGパスの滑らかさ
   - **Padding**：文字まわりの余白
   - 不要な枠は検出結果プレビュー上でクリックすると除外（グレー表示）
3. **STEP3/4** — 「SVGを生成する」→ 個別ダウンロード or 「すべてZIPで保存」

## 技術構成（実装メモ）

- OpenCV.js は不採用。Canvas標準API＋自前のOtsu二値化／BFS連結成分ラベリングで検出を実装（軽量・ビルド不要のため）
- 濁点等の分離パーツは、bbox間のギャップが「文字サイズ中央値 × Merge感度」以下ならUnion-Findで統合
- 読み順は行クラスタリング（縦方向の重なりで行を判定）→ 各行を左から右へソート
- SVG化は各文字を1000×1000キャンバスへ中央配置・余白付きで再描画してから ImageTracer.js でトレースし、黒パスのみ抽出（viewBox統一・全ファイル共通仕様）

## 既知の制限

- 縦書きは未対応（横書きのみ）
- OCRなし（ファイル名は `character_001.svg` 形式の連番）
- 手動補正は「枠のクリック除外」のみ。結合・分離・bbox手動調整は未実装
- Merge感度は文字サイズの中央値ベースの簡易ヒューリスティックなので、1画像内で文字サイズの差が大きいと精度が落ちる
- ImageTracer.jsのトレース結果は複数の`<path>`が結合される場合があり、複雑な字形では意図しない穴（白抜き部分）の扱いに差が出ることがある
